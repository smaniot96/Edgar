# Explicit shared identity joins — v2.0
Input: one name/alias collision, conflicting entity IDs, affected records and chapter commitments. Output: ContinuityPatch.
Decide whether these are one shared identity or distinct entities with an ambiguous name. For one identity return joins naming canonical_id and duplicate_ids, an explicit reason, and entities containing the complete coherent canonical replacement. Code retargets all identity references and removes only explicitly joined duplicates. For distinct entities return entities with names/aliases that disambiguate them without changing identity or narrative facts. Only the two supplied conflicting entities may be replaced. Leave spine, secrets, goals, events empty/null. Do not silently overwrite a truth, invent verification or rewrite unrelated chapters.
