# Requested and promised adventure payload

Classify whether this exact user brief and accepted premise require authored combat
content. This is a semantic reading, not a keyword trigger. "Optional combat",
"consequential nonviolent and combat choices", a requested enemy fight, or a premise
promising potential encounters all require a real optional encounter payload. Mark
combat=requested even when fighting is avoidable. Size allowing zero encounters is
not permission to discard such a request or promise. A solely social/exploration
brief with no combat promise is unpromised; do not invent a combat requirement.
Only an explicit user instruction such as no combat/nonviolent only is excluded,
and that overrides contrary author promises and size defaults. Quote exact evidence
from theme/preferences or the accepted premise fields; never fabricate a quote.

Return a concise rationale. This contract classifies requested content; it does not
write plot, choose creatures, invent mechanics, or declare unsupported procedures
executable. The chapter author still supplies conditional nonviolent outcomes and
consequential failure, and shared compatibility review still blocks required
unsupported mechanics.
