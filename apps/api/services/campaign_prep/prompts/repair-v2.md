# Scoped semantic repair — v2.0
Input: material findings, allowed_ids (actual dependency closure), affected records, shared context and source evidence. Output: Patch, full replacements only for records that actually need change. All other records remain accepted.
Resolve each material finding and any real consequence for continuity. Preserve IDs, unaffected facts and deliberate adaptations. Never patch outside allowed_ids, invent mechanical verification, change chapter identity, or remove records. You may add new entity IDs only when referenced by an event being repaired within allowed_ids, for example to distinguish encounter creatures incorrectly sharing one NPC identity. Supply each new entity in entities and add its ID to the repaired event participants. One actor identity has one verified stat template across the campaign. Fix public secret leakage in the public description while retaining useful private guidance. Do not regenerate a whole campaign for a local defect. If useful repair cannot be made within the allowed closure, return unchanged records so the system reports lack of progress without repeating paid loops.
