# Affected records only — v2.3
Input: concrete material findings, allowed_ids from their actual dependency closure, affected_records, continuity context, original source_evidence/images and verified creatures. Output: Patch containing only exact field_edits or complete record replacements that actually need change. All other material remains accepted.

Resolve the concrete source omission/contradiction and its real continuity consequences. Keep original IDs, unaffected facts, explicit adaptations and complete source-specific mechanics. A source profile must retain original numbers, traits, actions and spell information; catalogue names are not a reason to replace it. Retain original procedures, conditional timing, map facts and rewards in running notes. Original PDF facts are authoritative unless an explicit coherent adaptation documents the exception. Do not assume advanced spell/item execution exists just because a procedure is written down.

map_context includes selected original images from the affected records' WHOLE chapters, even when a map is outside the record's own origin pages. Physical-page/source_page references and source/image hashes identify them. Before repairing or introducing spatial directions, room connections, access, stairs or heights, compare the actual map pixels with keyed prose. OCR reading order, numbered rooms and earlier authored notes do not establish geometry. Preserve ambiguity explicitly with the reference; do not invent a certain connection or an exhaustive route guide. These additional images are read-only evidence and do not enlarge allowed_ids.

For a small prose contradiction in chapter source_notes or event dm_notes, prefer field_edits: supply its allowed record_id, field, old_text copied EXACTLY as one unique substring of the supplied accepted field, and new_text replacing only that substring. Empty new_text removes the substring. Edit the superseded instruction itself, preserving unrelated surrounding guidance; do not add another correction preface that leaves the false instruction active. If multiple copies conflict, identify each with unique surrounding text in separate non-overlapping edits. Do not also replace the same field through an event or chapter proposal. Original text remains in the durable task and repair receipt, separate from active DM guidance.

Use individual entities/secrets/goals/events patches for other local changes. chapters permits a complete Bundle replacement ONLY when that chapter's supplied kind=chapter content record ID is in allowed_ids. Preserve source page inventory, event/goal IDs and every unaffected record. Replace only affected running notes/items/checks through that bundle; unrelated contained entities/secrets/events/goals must be byte-for-byte unchanged. Do not replace an extensive reference with a short correction: use exact field_edits instead. Do not change chapter inventory or remove records. New entities may be added only when an affected repaired event references them (for example distinct creatures sharing one actor ID), via entities and that repaired event's participants. One actor identity has one exact profile.

A supplied kind=chapter content record is a private reference, not an Event. Never serialize it into events or use its content-record ID as an event/location ID. Use field_edits for its source_notes, preserving the real chapter's existing events and entities.

spine is null unless campaign_spine is in allowed_ids. Keep chapter IDs. Never patch outside the closure or invent source/mechanical verification. Fix player spoilers while retaining useful private truth. If no useful repair is possible within the closure, return empty unchanged patches so the system reports lack of progress without another paid loop. Do not regenerate the campaign for a local defect.
