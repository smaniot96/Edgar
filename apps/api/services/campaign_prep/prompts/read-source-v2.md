# Oversized source packet reading — v2.1
This fallback is used only when the original source exceeds the actual authoring context budget. Input: complete original OCR packet. Output: SourceReading.
Retain concrete campaign knowledge with physical page citations: identities, motives, cross-chapter truths, optional paths, exact quantities/stat profiles, original item procedures/DCs/failure tiers, timing, maps/access, rewards and outcomes. Do not compress distinctive rules into generic summaries. Identify chapter candidates and meaningful visual pages only from supplied physical pages. Mark ambiguous OCR columns/tables; do not invent statistics or missing connectivity. This is evidence for planning/authoring, not committed game state. Ordinary chapter calls receive original pages directly instead.
