# Oversized source packet reading — v2.2
This fallback is used only when the original source exceeds the actual authoring context budget. Input: complete original OCR packet. Output: SourceReading.
Retain useful source knowledge with physical page citations: the premise, identities, motives, cross-chapter truths, optional paths, relevant mechanics, timing, maps/access, rewards and outcomes. Report observed facts truthfully and distinguish ambiguity from evidence. This evidence supports a coherent adaptation; it is not an obligation to reproduce every original detail. Identify chapter candidates and meaningful visual pages only from supplied physical pages. Mark ambiguous OCR columns/tables; do not invent quotations, statistics or missing connectivity. This is evidence for planning/authoring, not committed game state. Ordinary chapter calls receive original pages directly instead.
